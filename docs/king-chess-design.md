## 1. 游戏概述

国王棋是一款 **2–4 人对战、秘密行动、d20 比速、后落吞先落** 的吃子争分局棋。

- 棋盘为**轮转式**：四名玩家各占一方位（上 / 下 / 左 / 右），环绕中央公共区。
- 三块构成物：
  - **棋局**（中央）：存放全部公共资源（公棋、私棋、道具）。不同棋局 = 不同玩法（类比麻将地区玩法）。
  - **棋场**：四面各一条 **4 格长条**棋盘，一格一子，箭头指示方向（**沿箭头循环**，见 §4/§5）。
  - **格栏**：个人区域，经典对局一般不用。
- 棋子分 **私棋**（玩家自带 4 种）与 **公棋**（公共，4–8 种）。

### 岚中对（第一个、也是最主流的棋局）

- 提供一座「王室核心」作为**得分目标**：通过吃棋、保棋等行为得分，先到指定分数者胜。
- 每场 **2–4 人**。开局骰一副 **20 面骰**按大小定行动顺序（棋场按顺时针分配），每人各行动完为一轮。

**单轮流程**（甲方确认，2026-09-09）

1. **刷新与决策（秘密）**：每人回合开始，四个棋场**随机刷新公棋**——每回合整场共刷新 **1–5 个公棋**（数量随机，各棋种按实现方定的概率抽取，见 §4.1）。玩家秘密决定本回合落几颗棋、落在哪个格（可放私棋，也可放此前吃到的公棋）。
2. **d20 速度（公开）**：全员决策完毕后，每人再骰一副 **20 面骰**，按大小定落棋顺序，点数最大者先落。
3. **落子互吃（公开）**：按 d20 顺序依次落子；同格冲突遵循「**后落的棋子吃掉先落的棋子**」。
4. **特殊效果轮（公开 · 限时 16 秒）**：全部落子与互吃完成后进入本轮——**马 / 车 / 骑士（公棋）与谋士 / 死士（私棋）等**棋子在此轮发挥自身特殊效果（前进、移动、收回、保护等）。全玩家统一至多 **16 秒** 行动时间，16 秒后统一结束（即使是单人热座也按统一窗口收束）。
5. **回合结束**：计分、公棋回收、私棋下场（见下），进入下一轮。

**胜利条件**：积满 **50 分**，或让场上其他玩家**无棋可用**。

**回收 / 下场**：被吃的**公棋**回收到棋局（除非特别标记）；被吃的**私棋**直接下场（国王除外——国王回手，见 §2/§4.5）。

## 2. 棋子一览（岚中对）

### 公棋（每场共 24：8 粮草 / 6 兵 / 4 马 / 4 车 / 2 骑士）

| 棋子 | 刷新难度 | 效果（**在特殊效果轮生效**） | 得分 |
| --- | --- | --- | --- |
| 粮草 | 最多 | — | 吃 +4 |
| 兵 | 较易 | 可直接放置 | 吃 +2 |
| 马 | 不易 | 吃后可在特殊效果轮沿箭头方向**前进一步** | — |
| 车 | 难 | 吃后可在本棋场内**无视格数移动**（不出棋场） | — |
| 骑士 | 难 | 吃后可在特殊效果轮**收回**（速度低于吃棋者则无法收回） | — |

### 私棋（被吃直接下场，国王除外；放置次数**无限制**）

| 棋子 | 效果 |
| --- | --- |
| 国王 | 共 **5 条命**；吃任意棋 +3 分。被吃后**回收至手**。**手里已无可用棋子时，国王自动回手并失去一次生命**；**手里完全无棋（国王生命耗尽 / 无棋可下）则失败下场**（见 §4.5） |
| 王后 | 被吃后你 **+8 分**（固定八分，甲方确认，纠正手册「rd12 分」笔误） |
| 死士 | 落地后己方所有棋子受保护——任何棋子被吃时由死士替吃，其位置被后落棋子替换 |
| 谋士 | 落地后你可收回一个场上棋子 |

## 3. 实现侧设计

遵循项目铁律：**裁决只在后端**（胜负判定、吃子、得分、随机骰全部由后端产生），前端只显示与转发。

### 复用现有机制

- **随机**：统一走后端 `DiceRoller`（禁止散落 `Random`）。
- **裁决**：新增 `kingchess` 领域包（对应现有 `combat/`），纯逻辑、可单测。
- **接口**：REST + DTO 契约；改契约必须前后端同步改。
- **账户**：复用现有 JWT / 登录 / Pinia auth store。

### 后端领域模型（草案）

```text
KingGame            — 一局状态机（gameId, phase, players, board, score, turn）
  phase             — WAITING / PLACING(秘密落子) / RESOLVING(d20+落子互吃) /
                      EFFECTS(特殊效果轮, 16s) / ROUND_END / FINISHED
  players[4]        — 每玩家：私棋手牌、已获公棋、当前得分、存活棋子、国王剩余生命
  board             — 四方棋场（每方 4 格，格子沿箭头循环）+ 棋局（公棋池）
  pieces            — 棋子实例（kind, owner, position, state）
  pendingActions    — 各玩家本回合秘密落子决策（结算前不公开）
```

### 结算算法（关键顺序，甲方确认）

```text
1. 收集全员 pendingActions（决策阶段不广播）。
2. 每人掷 d20 → 由大到小排序确定落子先后（平手按座位号，待确认）。
3. 按序落子；同格冲突按「后落吃先落」判定。
4. 【特殊效果轮】统一 16 秒窗口内结算：马前进 / 车移动 / 骑士收回 / 谋士收回 / 死士保护。
   各自与吃子的先后关系及细则 = 实现方默认（见 §5）。
5. 计分：吃子得分、国王命数、公棋回收 / 私棋下场处理、国王无棋可用回手扣命。
6. 胜负判定：>=50 分 或 他人无棋可用（含国王生命耗尽）→ FINISHED。
```

## 4. 甲方已确认（2026-09-09）—— 原「待确认」清单答复

1. **公棋刷新概率**：概率由实现方定；**每回合整场刷新 1–5 个公棋**（数量随机）。各棋种概率保留实现方默认权重（`SPAWN_WEIGHTS`），确认后固化。
2. **结算顺序**：**d20 速度 → 落子互吃 → 特殊效果轮**。特殊效果轮（马 / 车 / 骑士 / 谋士 / 死士）统一至多 **16 秒**行动时间，16 秒后结束。
3. **箭头方向映射**：**顺着箭头循环**——四格棋场箭头指示方向使格子形成环（0→1→2→3→0），马前进沿箭头方向可跨边界循环。
4. **循环冲突**：**不可以触发循环冲突**（沿箭头移动 / 前进时不得产生无限循环 / 自相矛盾的占位冲突，具体判定见 §5.3 实现方默认）。
5. **私棋放置次数**：**无限制**；但**手里无棋可用时国王回手并失去一次生命**，**手里完全无棋则为失败下场**（国王 5 命为生命上限，见 §2 国王）。
6. **王后分值**：**固定 8 分**（纠正手册「rd12 分」笔误）。胜利目标分仍按 **50** 为工作值。

## 5. 仍待甲方确认 / 实现方默认（开发前请拍板）

1. **特殊效果轮细则**：马前进 / 车移动 / 骑士收回 / 谋士收回 / 死士保护的具体触发与结算（如目标格被占、受保护时吃子如何判定）。实现方默认：逐项线性结算，先公棋后私棋，单回合每枚棋子至多触发一次。
2. **16 秒计时的纯逻辑建模**：前端提供统一倒计时与行动提交，超时视为「不行动」。后端在 EFFECTS 阶段收集各玩家动作并统一结算，不逐秒驱动。
3. **箭头循环的冲突判定**：沿箭头前进 / 移动时若目标格已占，如何判定（跳过 / 吃 / 停）。实现方默认：**不得占用已有棋子格，若唯一可行方向被占则本回合不触发移动**；循环推进时禁止因绕环导致同一棋子被重复结算（即「不可触发循环冲突」）。
4. **死士替吃后的连锁**：死士替吃后是否再次触发新格位冲突。实现方默认：不连锁，仅替换站位。
5. **骑士收回条件**：手册「速度低于吃棋者则无法收回」，速度取值与判定有待明确。实现方默认：以本次 d20 落子速度比较，收回不改变站位。
6. **胜利目标分**：当前按 **50** 作为工作值，是否与「无棋可用判负」并存确认。

## 6. 里程碑建议

- **M1 — 岚中对 · 本地可玩**：单机热座（2–4 人共屏轮流）或对简单 AI；覆盖完整回合流、d20、吃子计分、特殊效果轮（16 秒窗口）、国王回手扣命、胜负。先立住核心循环，范围可控。
- **M2 — 在线多人**：实时房间同步 + SSE 推送（参照现有 PVP 房间模式），特殊效果轮计时需服务端权威。
- **M3 — 扩展**：多棋局、非官方私棋 / 公棋、格栏玩法。
